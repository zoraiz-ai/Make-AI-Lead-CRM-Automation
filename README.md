# Project 40 – Make.com Advanced AI Lead CRM Automation

## Project Overview
An AI-powered Lead Qualification and CRM Automation system built using **Make.com, Airtable, and OpenAI**.

The workflow automatically receives sales leads, analyzes their information using AI, assigns a lead score, priority, and status, generates an AI summary, and saves the results in Airtable CRM.

## Key Features
- Automated lead capture using Make.com Webhooks
- AI-powered lead qualification with OpenAI
- Lead scoring from 0–100
- Automatic priority and status classification
- AI-generated lead summaries
- Airtable CRM integration
- Duplicate lead detection using email
- Automatic creation of new leads
- Automatic updates to existing leads
- JSON parsing and conditional routing

## Technologies Used
- Make.com
- OpenAI API
- Airtable
- Webhooks
- JSON
- Routers, Filters, and Array Aggregator

## Workflow
1. Receive lead information through a webhook.
2. Analyze the lead using OpenAI.
3. Parse the AI-generated JSON response.
4. Search Airtable for an existing lead.
5. Update the existing record or create a new record.
6. Store the lead score, priority, status, and AI summary in Airtable.
